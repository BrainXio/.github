# BrainXio

## Mission

BrainXio builds agent infrastructure and tooling for development teams.

## Tech Stack

- **Languages**: Python, Bash
- **AI Integration**: Ollama, Claude API
- **Tooling**: FastMCP, Docker, Caddy
- **Version Control**: Git with worktree-based development

## Open Source Projects

- [brainxio/workflows](https://github.com/brainxio/workflows) — Reusable GitHub Actions workflow callers
- [brainxio/tools](https://github.com/brainxio/tools) — MCP servers for agent coordination, documentation, economy, knowledge, security, and thresholds
- [brainxio/.claude](https://github.com/brainxio/.claude) — Runtime configuration: hooks, rules, skills, and profiles
- [brainxio/.github](https://github.com/brainxio/.github) — Org-wide defaults, workflows, and issue templates
- [brainxio/.agents](https://github.com/brainxio/.agents) — Knowledge base and internal documentation
- [brainxio/.ollama](https://github.com/brainxio/.ollama) — Model definitions and modelfiles for Ollama
