# BrainXio

## Mission

BrainXio builds agent infrastructure and tooling for development teams.

## Tech Stack

- **Languages**: Python, Bash
- **AI Integration**: Ollama, Claude API
- **Tooling**: FastMCP, Docker, Caddy
- **Version Control**: Git with worktree-based development

## Open Source Projects

- [brainxio/.github](https://github.com/brainxio/.github) — Reusable GitHub Actions workflows, composite actions, and org defaults
- [brainxio/cicd](https://github.com/brainxio/cicd) — Reusable CI workflows (Python, Go, Rust, TypeScript, publishing, security)
- [brainxio/actions](https://github.com/brainxio/actions) — Composite setup actions for toolchain installation
- [brainxio/.githooks](https://github.com/brainxio/.githooks) — Shared git hooks for the organization
