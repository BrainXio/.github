# Skill: Pull Request

**Purpose**: Create well-formed pull requests that enable fast, high-quality review.

**Steps**:

1. Create a focused branch from the correct base.
2. Ensure all changes are committed and pushed.
3. Write a clear PR title and description with context, testing notes, and linked issues.
4. Request review from appropriate roles.
5. Respond to feedback promptly and update as needed.

**Success Criteria**: PR is focused, description is complete, and CI passes before requesting review.
