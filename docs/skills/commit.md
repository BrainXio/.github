# Skill: Commit

**Purpose**: Create clean, atomic commits that follow project standards.

**Steps**:

1. Ensure all changes are staged and relevant to a single logical unit.
2. Write a clear, imperative commit message (max 72 characters for subject).
3. Include body if needed explaining why the change was made.
4. Run `git commit` and verify the commit hash.

**Success Criteria**: Commit is atomic, message is clear, and no unrelated files are included.

**Escalation**: If commit would affect public history or requires review, escalate to Personal or Core before pushing.
