# Skill: Issue Triage

**Purpose**: Quickly categorize and route issues to the correct owner and priority.

**Steps**:

1. Read the issue and reproduce if possible.
2. Classify: Bug / Feature / Documentation / Question.
3. Assign priority (P0–P3) based on impact and urgency.
4. Assign to appropriate role or label.
5. Add clear next-action comment.

**Success Criteria**: Issue has correct labels, priority, assignee, and a clear next step within 24 hours.
