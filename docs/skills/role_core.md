# Skill: Core Role Decision Making

**Purpose**: Make high-quality, sovereignty-preserving decisions as the Human Engineer / Core Role.

**Steps**:

1. Gather input from Personal and Resonant roles.
2. Evaluate against long-term vision and values.
3. Consider resource constraints (subscription tier, hardware, time).
4. Communicate decision clearly with rationale and success criteria.
5. Log the decision in the appropriate A.E.D. or roadmap document.

**Success Criteria**:

- Decision is explicit, time-boxed when needed, and recorded.
- All affected roles understand the "why" and next actions.
