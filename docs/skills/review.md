# Skill: Code Review

**Purpose**: Provide high-signal, constructive feedback that improves code quality without unnecessary friction.

**Steps**:

1. Read the full PR and understand the intent.
2. Check for correctness, clarity, tests, and adherence to standards.
3. Comment on specific lines with clear suggestions.
4. Approve only when criteria are met or note blocking issues.

**Success Criteria**: Feedback is specific, actionable, and respectful. Blocking issues are clearly justified.
