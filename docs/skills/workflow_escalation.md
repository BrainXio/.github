# Skill: Escalation Workflow

**Purpose**: Escalate issues cleanly and quickly while preserving context and sovereignty.

**Steps**:

1. Clearly state the issue, current role, and attempted solution.
2. Include relevant logs, hardware tier, and attempted mitigations.
3. Tag the correct next role (Personal or Core).
4. Wait for acknowledgment before continuing related work.

**Success Criteria**:

- Escalation contains context, impact, and proposed options (if any).
- Done within 5 minutes of discovering a blocker that exceeds current tier.

**Escalation**: If no response within 30 minutes during active sprint, re-escalate with higher urgency.
