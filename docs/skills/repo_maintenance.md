# Skill: Repository Maintenance

**Purpose**: Keep repositories clean, consistent, and healthy over time.

**Steps**:

1. Run regular housekeeping: remove unused branches, close stale issues/PRs.
2. Update documentation when standards change.
3. Ensure `.github/` templates, workflows, and labels are synchronized.
4. Check for large files, secrets, or sensitive data.
5. Maintain clean commit history through proper rebasing/squashing when needed.

**Success Criteria**:

- No more than 5 stale branches older than 30 days.
- All open PRs and issues have recent activity or clear next steps.
- Repository passes all CI checks.

**Escalation**: Structural changes or history rewrites must go through Personal → Core.
