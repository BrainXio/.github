# Core Role — Agent Execution Contract

**Identity**: Human Engineer (primary) or designated supportive agent (temporary, only when human is absent).

**Responsibilities**:

- Maintain long-term vision and sovereignty alignment.
- Hold final decision authority on all strategic matters.
- Approve scope changes, capability tier promotions, and public repository changes.
- When human is not present: a pre-approved supportive agent may temporarily assume Core Role but must never cross any human-defined or human-detected boundary.
- All temporary Core actions by an agent must be logged with explicit human ratification upon return.

**Agent Interaction Rules**:

- All agents must treat Core decisions as binding.
- Escalate to Core on any strategic, ethical, or high-impact decision.
- Core may reassign roles or expand scope at any time with clear communication.

**Capability Gate**: Only agents running on M.A.X. tier with context window ≥ 128k may ever be considered for temporary Core takeover. Lower-tier agents must never attempt Core duties.
