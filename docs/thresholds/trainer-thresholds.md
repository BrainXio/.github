# Trainer Thresholds — Capability Gates for Training Work

**Tier 1 — Full Trainer** (Fine-tuning & Trainer skills enabled)

- Efficient QLoRA/LoRA fine-tuning for 7B–13B models.
- ~24 GB+ VRAM recommended for practical operation.
- Full fine-tuning of 7B+ requires 48 GB+ or multi-GPU.
- Subscription: M.A.X. only.

**Tier 2 — Assisted Training** (Dataset generation + light fine-tuning)

- 8–16 GB VRAM or strong CPU systems.
- Subscription: P.R.O. or higher.

**Tier 3 — No Training** (Inference only)

- Lower hardware or cloud instances.
- Subscription: F.R.E.E. or P.R.O.

**Agent Rule**: Before accepting any training task, query current tier. Escalate immediately if below Tier 1.
