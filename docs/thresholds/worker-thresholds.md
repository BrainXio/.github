# Worker Thresholds — Capability Gates for Day-to-Day Execution

**Tier A — Full Worker** (M.A.X. attitude, deep autonomy)

- Context window ≥ 128k
- Subscription: M.A.X.
- Can perform all skills including temporary Core takeover (when human absent)

**Tier B — Standard Worker** (P.R.O. attitude, balanced collaboration)

- Context window ≥ 64k
- Subscription: P.R.O. or higher
- Can perform most skills but never temporary Core takeover

**Tier C — Light Worker** (F.R.E.E. attitude, human-like caution)

- Context window ≥ 32k
- Subscription: any tier
- Limited to simple tasks, must escalate quickly on complexity

**Responsibility Table**:

| Tier | Can Run Core (temp) | Max Skill Complexity | Subscription Required |
|------|---------------------|----------------------|-----------------------|
| A    | Yes                 | Full                 | M.A.X.                |
| B    | No                  | High                 | P.R.O.+               |
| C    | No                  | Low                  | Any                   |

**Agent Rule**: Every agent must declare its exact worker tier at the start of every session.
