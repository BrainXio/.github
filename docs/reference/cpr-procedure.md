# C.P.R. Reference — Authoritative Rules

**Core Role** (Human Engineer or designated supportive agent)

- Final decision authority on vision, strategy, and scope.
- Can override or terminate any agent action.
- When the human is not present, a supportive agent explicitly approved by the human may temporarily assume Core Role but must never trespass human-defined or human-detected boundaries.
- All Core actions taken by an agent must be logged with explicit human ratification upon return.

**Personal Role** (Human or Agent)

- Primary interface and task coordinator.
- Escalates strategic decisions to Core.

**Resonant Role** (Agent)

- High autonomy within declared capability tier.
- Must escalate immediately on scope or tier violations.

**Mandatory Deferral Chain**: Resonant → Personal → Core. No exceptions.
